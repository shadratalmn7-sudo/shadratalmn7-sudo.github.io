# بوت شذرات للدعم — Cloudflare Worker

هذا المجلد يحتوي بوت Telegram بسيط بدون ذكاء اصطناعي، يعتمد على أزرار وقوائم ثابتة لتقليل الأخطاء والتكاليف.

## الوظائف
- قائمة رئيسية للمنح والخدمات والأسعار ومشاكل الموقع والتواصل مع الدعم.
- روابط مباشرة لصفحات شذرات بدل تكرار معلومات قد تصبح قديمة.
- لا يعرض أي معلومات إدارية.
- لا يدخل في محادثات عامة خارج الدراسة والمنح وخدمات شذرات.
- يمكنه تحويل رسائل الطلاب إلى حساب دعم عند إضافة `ADMIN_CHAT_ID`.

## المتغيرات السرية المطلوبة في Cloudflare
أضف هذه القيم من Settings > Variables and Secrets:

- `BOT_TOKEN` — توكن البوت من BotFather. خزّنه كـ Secret.
- `ADMIN_CHAT_ID` — اختياري. معرّف محادثة حساب الدعم. للحصول عليه بعد تشغيل البوت، أرسل `/id` للبوت.

لا تضع BOT_TOKEN داخل GitHub أو داخل worker.js.

## ربط Telegram بالـ Worker
بعد نشر الـ Worker ومعرفة رابطه، افتح هذا الرابط في المتصفح بعد استبدال القيم:

`https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://<WORKER_URL>`

إذا ظهر `"ok":true` فالربط نجح.

## اختبار سريع
1. افتح رابط الـ Worker في المتصفح: يجب أن يظهر `Shadrat Support Bot is running ✅`.
2. أرسل `/start` إلى `@ShadratSupportBot`.
3. يجب أن تظهر قائمة الأزرار.
4. أرسل `/id` للحصول على Chat ID إذا أردت تحويل رسائل الدعم إليك.
